# Shani Design Studio (شانی ڈیزائن اسٹوڈیو)
> "We Design Your Ideas"

A modern, bilingual (English & Urdu) web portal for **Shani Design Studio**, featuring 11 categories and 117+ bespoke graphic design services.

## ✨ Features
- **Bilingual Interface:** Instant seamless switching between English and Urdu with full RTL/LTR support and Noto Nastaliq Urdu typography.
- **Smart Category Explorer:** Clean 11 categories browsing grid without exposing overwhelming service lists upfront.
- **Add to Cart Inquiry System:** Clients select desired design services into a cart and submit their project brief directly via WhatsApp without phone number or deadline friction.
- **Customer Satisfaction Modal:** Warm "Happy Notes" greeting after order submission.
- **Custom 404 & Offline Protection:** Dynamic animated swinging desk lamp scene for network dropouts and 404 routes.
- **Zero Build Dependencies:** Pure Vanilla HTML5, CSS3, Tailwind CSS (CDN), and JavaScript. Ready to deploy instantly on GitHub Pages, Netlify, or Vercel.

## 🚀 Live Deployment
Simply open `index.html` in any modern web browser or deploy to GitHub Pages:
1. Go to repository **Settings** > **Pages**
2. Under **Build and deployment**, set source to `Deploy from a branch` -> `main` / `root`
3. Save and your studio website is live!
